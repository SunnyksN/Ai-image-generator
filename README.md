# Ai-image-generator
🎨 AI Style Image Generator

An AI-powered web application that generates high-quality images in multiple artistic styles such as Anime, Cartoon, Sketch, and Cinematic using state-of-the-art diffusion models like Stable Diffusion XL.

Built with Streamlit, this project provides an intuitive interface for real-time image generation from text prompts.

🚀 Features
✍️ Text-to-Image Generation
Generate images from natural language prompts
🎨 Multiple Styles მხარდაჭერა
Anime
Cartoon (Pixar-style)
Pencil Sketch
Cinematic
⚙️ Prompt Customization
Style-based prompt enhancement
Negative prompts for better quality
🖼️ Real-Time Preview
Instantly view generated images in the UI
💾 Download Option
Save generated images locally
🧠 Tech Stack
Frontend/UI: Streamlit
Model: Stable Diffusion XL
Libraries: Diffusers, Transformers, Torch
Model Hosting: Hugging Face
